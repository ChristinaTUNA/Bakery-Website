An **e-Commerce bakery website** that specializes in cakes, cookies, doughnuts, breads, and seasonal baked goods. This project emphasizes **modern design, responsive layout, and smooth user experience** to demonstrate skills in **frontend web development** and **UI/UX design**.  <br>

## 📚 Academic Context  

This project was developed as my **First Year Web Fundamentals Final Assessment**.  
- The original assignment required creating a **basic static website**.  
- I extended the requirements by:  
  - Implementing **responsive design** (mobile-first, flexible layouts).  
  - Adding **JavaScript interactivity** (form validation, cart system, dynamic nav bar).  
  - Applying **modern UI/UX principles** (visual hierarchy, consistent branding, minimal layout).

## 🎨 Design  

- **Color Palette**: 🟢 Green (#228B22), 🟤 Beige (#F5F5DC), ⚫ Dark Gray (#333333)  
- **Typography**: Poppins (main), Verdana (buttons), Times New Roman (footer date), Roboto (inputs)  
- **Layout**: Grid-based, responsive, mobile-first  
- **Interactive Elements**: Hover effects, smooth transitions, modal windows  



## 🎯 Key Features  

- **Responsive Navigation Bar** – mobile-first with hamburger menu  
- **Hero Landing Section** – attention-grabbing banner with CTA  
- **Shop All Page** – grid layout for products with price & sale indicators  
- **About Us Page** – brand story and mission statement  
- **Contact Page** – form + bakery info with validation  
- **Login/Signup Pages** – demo authentication with form validation  
- **Cart & Checkout** – add/remove products and proceed to payment (demo)  
- **Consistent Branding** – green + beige theme with clean typography
